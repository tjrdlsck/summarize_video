# 제품 요구사항 정의서 (PRD): SermonCutter AI

## 1. 프로젝트 개요 (Project Overview)
**SermonCutter AI**는 긴 기독교 설교 영상을 인공지능(AI) 기술을 활용해 자동으로 분석, 요약하고, 편집자가 필요한 핵심 구간을 빠르게 찾아 편집할 수 있도록 돕는 **설교 영상 편집 지원 서비스**입니다.

- **목적**: 1시간 30분 내외의 긴 설교 영상에서 핵심 메시지를 추출하고, 소셜 미디어용 숏츠(Shorts) 제작 및 블로그 포스팅 초안 작성을 자동화하여 미디어 사역의 효율성을 극대화함.
- **핵심 가치**: 시간 절약, 메시지 중심의 편집 구간 탐색, 다채로운 콘텐츠 재가공(One-Source Multi-Use).

## 2. 타겟 사용자 (Target Audience)
1. **교회 미디어 팀 편집자**: 설교 풀 영상을 편집하여 하이라이트나 숏츠를 제작해야 하는 실무자.
2. **온라인 사역 담당 목회자**: 설교 내용을 텍스트로 정리하여 주보나 블로그, SNS에 공유하고자 하는 목회자.
3. **설교 내용을 공부하는 성도**: 설교의 전체 구조를 파악하고 특정 주제의 구간을 다시 듣고 싶은 성도.

## 3. 주요 기능 (Core Features)

### 3.1. 영상 수집 및 전처리
- **유튜브 연동**: 유튜브 URL 입력 시 자동 다운로드 및 분석.
- **로컬 업로드**: 사용자가 보유한 MP4 등 영상 파일 직접 업로드.
- **음성 추출 및 인식(ASR)**: `mlx-whisper`를 활용하여 고정밀 한국어 자막 생성 (타임스탬프 포함).

### 3.2. 설교 특화 AI 분석 (Sermon-Specific Analysis)
- **성경 구절 자동 감지**: 설교 중 인용되는 성경 본문(예: "요한복음 3장 16절")을 AI가 인식하여 해당 구간을 **[성경 봉독]** 챕터로 자동 분류하고, 해당 구절의 전문을 주석으로 병기.
- **설교 대지(Points) 추출**: "첫째", "둘째" 등 설교의 핵심 대지를 파악하여 블로그 포스팅의 소제목으로 자동 변환.
- **기도 및 찬양 구간 분리**: 설교 전후의 찬양이나 마무리 기도를 별도 챕터로 구분하여, 순수 설교 부분만 빠르게 편집할 수 있도록 지원.

### 3.3. 편집 및 재가공 지원
- **블로그 포스팅 엔진**: `TextRefiner`를 통해 구어체 설교를 문어체 블로그 글로 변환. 타임스탬프를 유지하여 독자가 특정 대목의 영상을 즉시 찾아볼 수 있는 링크 구조 제공.
- **AI 숏츠(Shorts) 후보 추천**: 설교 중 감동적인 예화나 결론 부분의 핵심 메시지를 AI가 1분 이내 분량으로 추천.
- **프리미어 프로 XML 익스포트**: AI가 구분한 챕터별로 컷이 나뉘어 있는 시퀀스 데이터를 생성하여 편집 시간 80% 단축.

## 4. 기술 사양 및 사용 환경 (Technical Specs & Environment)
- **사용 환경**: **개인용 데스크탑/노트북 환경** 최적화 (Single User).
- **실행 방식**: 로컬 Python 환경(venv)에서 FastAPI 서버 실행 후 브라우저 접속.
- **컴퓨팅 자원**: Apple Silicon(M1/M2/M3) 및 GPU 가속을 활용한 온디바이스(On-device) 음성 인식(Whisper) 지원으로 개인정보 보호 및 비용 절감.
- **외부 API**: 고차원 추론이 필요한 요약 및 윤문 작업에만 Google Gemini API 활용.

## 5. 사용자 흐름 (User Workflow)
1. **입력**: 편집할 설교 영상 업로드 또는 유튜브 주소 복사.
2. **자동 분석**: Whisper가 자막을 따고, Gemini가 설교 구조(본문, 대지, 기도)를 분석.
3. **리뷰 및 수정**: 생성된 블로그 초안과 챕터를 확인하고 필요시 제목 수정.
4. **내보내기**: 
   - 하이라이트 구간을 선택하여 프리미어용 XML 파일 다운로드.
   - 블로그 글을 복사하여 교회 홈페이지나 SNS에 게시.
   - 자동 생성된 숏츠 영상을 확인하고 소셜 미디어용으로 저장.

## 6. 향후 확장성 (Future Roadmap)
- **다국어 자막 생성**: 해외 선교용 영문/중문 자막 자동 생성 지원.
- **다빈치 리졸브(DaVinci Resolve) 지원**: XML 포맷 호환성 확장을 통해 다양한 편집 툴 지원.
- **설교 아카이브 검색**: 과거 설교 자막 데이터를 데이터베이스화하여 특정 키워드(예: "위로", "십자가")가 포함된 설교 구간 검색 기능.
